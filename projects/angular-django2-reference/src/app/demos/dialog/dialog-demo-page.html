Dialog

The dialog schematic compiles an OpenUI dialog element (widgets/dialog) into a standalone Angular Material dialog component. Its uses.open and uses.modal attributes become the open and modal signals, and produces.close and produces.cancel become the closed and cancelled outputs.

Try the generated dialog Modal

A modal dialog has a backdrop and sets aria-modal. Focus moves into the dialog and returns to the button when it closes. A button closes the dialog; Escape or a backdrop click dismisses it.

@switch (outcome()) { @case ('closed') { Last outcome: closed (produces.close). } @case ('cancelled') { Last outcome: dismissed (produces.cancel). } @default { No dialog has ended yet. } }
