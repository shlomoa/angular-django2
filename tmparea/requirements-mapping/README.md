# Requirements mapping intermediate results

This directory stores ephemeral, issue-specific results for the requirements
mapping Epic. Each result file is named:

`<issue-number>-<slug>.md`

Each file must state the source paths searched or read, exact results, completed
plan steps, and the required user-intervention outcome. Before closing its
issue, the author must update each dependent issue and the Epic with the result
path and one-line outcome; if that cannot be done, the file must request the
user to make the update.
