# Why \<ng-container\> is Still Essential

## \<ng-container\> BKM

- No DOM Pollution: It groups multiple elements or acts as a logical placeholder without rendering an actual DOM element (rendered as a comment node), preserving your CSS layouts (like CSS Grid or Flexbox). [[1](https://angular.dev/api/core/ng-container), [2](https://techblogs.42gears.com/angular-difference-between-ng-container-and-ng-template/)]

- Dynamic Component & Template Rendering: It is required for dynamic rendering features like [ngComponentOutlet] and [ngTemplateOutlet]. [[1](https://blog.angular-university.io/angular-ng-template-ng-container-ngtemplateoutlet/), [2](https://angular.dev/guide/templates/ng-container)]

- Grouping with Control Flow: Even with @if, you still need a grouping element when you want to conditionally render multiple sibling elements without adding an unnecessary wrapper tag like a <div>. [[1](https://www.youtube.com/watch?v=x3KaykQBLF0&t=160), [2](https://angular.dev/guide/templates/ng-container)]

## Example of schematics and generated templates CSS-related layout issues

Currently we have have [complex-component/index.ts](file:///c:/Users/shlom/source/repos/shlomoa/angular-django2/projects/angular-django2/schematics/complex-component/index.ts#L318-L322) open at line 321:

```typescript
function projectionSlots(name: string): string {
  return `<ng-content select="[${name}-header]"></ng-content>
<ng-content></ng-content>
<ng-content select="[${name}-actions]"></ng-content>`;
}
```

This points directly to where `<ng-container>` is critical in **schematic-generated component architecture**:

- When consumers use a multi-slot component generated by `complex-component`, they often need to project **multiple sibling elements** (e.g. multiple action buttons into `[${name}-actions]`, or multiple header items into `[${name}-header]`).

- If consumers wrap those siblings in a `<div>`, that `<div>` gets projected into the `<mat-card>`, breaking the internal flex/grid alignment of `<mat-card-header>` and `<mat-card-actions>`.

- The **Angular BKM** is to project them via `<ng-container>`:

  ```html
  <ng-container dashboard-card-actions>
    <button mat-button>Cancel</button>
    <button mat-flat-button>Save</button>
  </ng-container>
  ```
